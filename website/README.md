# Rivals — Official Website

Public marketing site for the Rivals mobile app.

## Stack
- Next.js 15 (App Router) + TypeScript
- Geist font (self-hosted)
- Plain CSS

## Local dev
npm install
npm run dev

## Build
npm run build
npm run start

## Deploy (Vercel)
1. Push to GitHub.
2. Import into Vercel.
3. Root Directory = `website`.
4. Deploy.
